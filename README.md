# FDE 国企智能审批提效平台 · 演示中心 (Demo)

基于 2026-09-05 会议核心决议构建，面向国企食品加工厂业务场景的 **AI 审批提效与合规穿透演示系统**。

## 🎯 业务定位与核心价值

- **一线减负而非挑刺监督**：辅助经办人自查漏洞，协助审批领导一键出具专业合规意见。
- **两阶段场景全覆盖**：
  1. **基础要素交叉勾稽校验**：表单申报总金额 vs 合同扫描附件明细累加、供方主体、税率账期。
  2. **企业制度 Grounding 穿透溯源**：基于向量数据库检索《大额资金办法》《食品原料质量规范》《直采直供细则》，给出带条文依据的裁定。
- **多岗位意见一次性全量生成、按岗分发**：一次全量推演，分别输出【财务部初审意见】、【法务风控意见】、【分管领导批示建议】，支持一键复制。

## 🚀 预置 3 大典型场景

1. **案例一（金额差额 5 万 + 缺三重一大决议）**：《万吨大豆毛油采购》，表单申报 120 万 vs 附件清单 115 万，且超百万未附党委会纪要文号。
2. **案例二（食品质量标准与企业制度冲突）**：《面包发酵改良剂供货协议》，供方合同约定 95% 合格率验收，与集团《食品安全质量控制规范 v3.2》强制要求的 99.8% 底线冲突。
3. **案例三（合规免检极速放行）**：《基地鲜果冷链运输服务协议》，表单与附件完全匹配，入围合格目录符合免招标标准，AI 给出“建议快速通过”。

## 🚀 部署与上线发布

### 方案一：Vercel 一键云端发布（推荐）

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fanong8090%2Ffde)

1. 将本仓库推送到 GitHub：`git push -u origin main`
2. 登录 [Vercel](https://vercel.com/new)，选择导入 `anong8090/fde` 仓库；
3. Framework 预设自动识别为 **Next.js**，直接点击 **Deploy** 按钮；
4. 约 1 分钟即可生成全球加速的公网 HTTPS 访问域名（如 `https://fde-approval.vercel.app`）。

### 方案二：Docker 容器化与独立服务器部署

```bash
# 1. 构建独立镜像
docker build -t fde-demo .

# 2. 启动容器生产服务
docker run -d -p 3000:3000 --name fde-demo-app --restart always fde-demo
```
